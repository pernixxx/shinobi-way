# Shinobi Way

A Naruto adventure for Minecraft Java Edition 26.3: jutsu with hand seals and chakra, the Shinobi Path (levels, clans,
ranks), ninja tools, movement from wall runs to water walking, bosses, the Tailed Beast Kurama, and the Hidden Leaf
Village to explore.

## Install
1. Have Minecraft Java Edition and its official launcher (open it once and sign in).
2. Download **[ShinobiWayInstaller.exe](https://github.com/pernixxx/shinobi-way/releases/latest/download/ShinobiWayInstaller.exe)**
   and run it. Windows may say "Windows protected your PC" because the installer isn't signed: click **More info**,
   then **Run anyway**.
3. Close the Minecraft Launcher, press **Install**, then open the launcher, pick **Shinobi Way** next to Play, and
   press Play.

The installer adds a launcher profile with its own game folder (your other worlds and mods aren't touched), Fabric,
Fabric API, Sodium, Iris and the Shinobi Shaders shader pack. **To update**, run the installer again and press
Update. Every release is on the [Releases page](https://github.com/pernixxx/shinobi-way/releases).
